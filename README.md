# Cultura digital no PIBID

Site experimental do minicurso **Cultura digital e produção de conhecimento no PIBID através de práticas e experiências do subprojeto de História**.

A página foi desenhada como uma experiência colaborativa para bolsistas dos diferentes subprojetos do PIBID. Nesta primeira versão, os dados são demonstrativos. A etapa seguinte conectará o mural às respostas de um formulário para atualização dinâmica durante a transmissão.

## Arquivos
- `index.html`: estrutura da página
- `style.css`: identidade visual e responsividade
- `script.js`: cards, filtros, indicadores e dados demonstrativos
